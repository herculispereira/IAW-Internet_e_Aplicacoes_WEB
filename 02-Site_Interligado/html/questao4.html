HTML

O que é?

HTML (acrônimo para a expressão inglesa HyperText Markup Language, que significa Linguagem de Marcação de Hipertexto) é uma linguagem de marcação utilizada para produzir páginas na Web. Documentos HTML podem ser interpretados por navegadores.

Sobre o curso:

Este curso ensina desde os conceitos básicos da linguagem HTML até a criação de formulários para a Web. Ideal para iniciantes ou para quem deseja um guia de consulta.

Também possui um glossário com as palavras mais utilizadas na Internet.

Dreamweaver

O que é?

O Macromedia Dreamweaver é um software de criação para a Web desenvolvido pela Macromedia, posteriormente adquirida pela Adobe Systems.

Versões iniciais da aplicação funcionavam como editores HTML WYSIWYG ("What You See Is What You Get"), mas versões posteriores incorporaram suporte para XHTML, CSS, JavaScript e outras tecnologias Web.

Sobre o curso:

Torne-se um Web Designer e aprenda a utilizar o Dreamweaver CS3 para criação de sites.

O treinamento possui dezenas de tutoriais ilustrados com imagens e gráficos explicativos, além de mais de 50 videoaulas em português.

Flash

O que é?

Adobe Flash, anteriormente Macromedia Flash, é um software de gráficos vetoriais utilizado principalmente para criar animações interativas em páginas Web.

Também permite trabalhar com imagens bitmap, vídeos e desenvolver aplicações utilizando a linguagem de programação ActionScript.

Sobre o curso:

Este curso apresenta os conhecimentos necessários para o desenvolvimento de sites, jogos e aplicações multimídia em ambiente Flash.

Durante as 21 aulas, o aluno aprenderá sobre ferramentas de desenho, animações, camadas, cenas, símbolos, movie clips e ActionScript.

Fireworks

O que é?

O Fireworks é um editor de imagens desenvolvido pela Macromedia e posteriormente adquirido pela Adobe.

Suas funcionalidades são voltadas para a publicação gráfica na Internet, incluindo suporte a GIF animado, PNG e imagens fatiadas.

Sobre o curso:

O curso ensina a trabalhar com ferramentas de edição de imagens, vetores, textos, botões e camadas no Fireworks 8.

Também aborda filtros, criação de logomarcas, tratamento de imagens e desenvolvimento de websites.
